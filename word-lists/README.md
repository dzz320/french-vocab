# 法语分级词表（可直接导入小程序）

六份 CSV，都是 UTF-8 with BOM + RFC4180 引号规范，能直接被小程序里「生词本 → 导入词表」解析，**六列全部能自动对位，不需要手动改列映射**。

| 文件 | 建议词库名 | 等级 | 词条数 | 来源 |
|---|---|---|---|---|
| `A1.csv` | A1 库 | A1 | 209 | 手工精选 |
| `A2.csv` | A2 库 | A2 | 202 | 手工精选 |
| `B1.csv` | B1 库 | B1 | **1717** | FLELex 定级 + Lexique383 音标 |
| `B1-表达.csv` | B1 表达库 | B1 | 143 | 手工精选（B1 的固定搭配与连接词） |
| `B2.csv` | B2 库 | B2 | 211 | 手工精选 |
| `tech.csv` | 工程师库 | （不设等级） | 79 | 手工精选 |

**手工精选的五份之间零重词**（A1 / A2 / B1-表达 / B2 / tech，已逐词校验），导入时不会互相弹提示。

`B1.csv` 是完整词表，与上面几份**有 93 个词形重叠**（A1 15、A2 30、B2 28、tech 20）。这是刻意的，不是失误——原因见下面「B1 完整词表是怎么来的」。

## 怎么导入

1. 把 CSV 发到「微信文件传输助手」（或用任意方式存进微信聊天记录）。
2. 打开小程序 → 生词本 → 顶部词库条右侧的「＋ 词库管理」→「导入词表」。
3. 选目标词库：点「＋ 新建词库」，名字填上表里的建议名，等级芯片选对应等级（工程师库可以不选等级）。
4. 点「选择文件」，从聊天记录里选 CSV。解析后会自动进入预览：
   - 表头、列映射应该已经全部对好（六列：单词 / 释义 / 音标 / 词性 / 例句 / 例句翻译）；
   - 「可导入」数量应该等于词条数，「缺释义」应该是 0（所以不用花 AI 调用去补）；
   - 预览只显示前 100 条，剩下的会以「还有 N 条未显示」提示。
5. 点保存。会按 200 条一片写入。1717 条的 B1 就是 9 片（8×200 + 117）。

建议**一份词表建一个词库**，这样生词本顶部可以按库筛选，SRS 复习也是全库混着走，不冲突。
想按顺序推进的话，一个自然的用法是：先把 A1 导进去开始复习，等 A1 里「已掌握」的比例上来了，再把 A2 导进来——随时能导，也不会互相干扰。

## 列的含义

| 列名 | 说明 |
|---|---|
| `mot` | 法语词条（原形）。词条本身不带冠词，阴阳性在词性列体现 |
| `中文释义` | 中文释义，多个义项用「；」分隔 |
| `音标` | 标准 IPA，不带斜杠，用 `.` 标音节边界 |
| `词性` | 取值限定在 `n.m. n.f. v. adj. adv. prép. conj. pron. det. num. interj. loc.` 之内 |
| `例句` | 法语例句，与词条严格对照 |
| `例句翻译` | 例句的中文翻译 |

之所以选这组表头名，是因为它们正好命中解析器的表头词库（`mot` / `中文释义` / `音标` / `词性` / `例句` / `例句翻译`），
其中「例句翻译」必须排在「例句」之前被认领，否则会被当成释义列——这是解析器内部已经处理好的顺序。

## B1 完整词表是怎么来的

`B1.csv` 不是手工写的，而是从两个学术资源合成的：

- **FLELex**（UCLouvain，法语作为外语的分级词表）负责**定级** —— 14,236 个词条各自带一个推断出的 CEFR 等级；
- **Lexique383**（lexique.org）负责**词形、音标、词性、阴阳性** —— 14 万个词形，音标是语料实测值。

产线是：取 FLELex 标为 B1 的 1753 条 → 用 Lexique383 把屈折形归原形（`grecque`→`grec`、`mesdames`→`madame`）→
音标从 Lexique 的音素表转成标准 IPA → 词性/阴阳性取自 Lexique → 中文释义和例句批量生成后逐条机械校验。
最终 **1717 条**（丢掉了 1 条碎片 `-ci`，合并了 35 条同形/重复条目）。

### 两个必须知道的性质

**① 收录的是「到 B1 这一级才成为新知识」的那个义项。**

FLELex 是按「词 + 词性」分别定级的，所以 `pouvoir` 是**动词 A1 / 名词 B1**、`être` 是**动词 A1 / 名词 B1**。
这带来两个后果，都是刻意的：

- `pouvoir` 在这份 B1 里是**名词**「权力」，不是动词「能够」；
- 同理 `impossible`（名词 l'impossible，形容词义 A1）、`humain`（名词 un humain）、`politique`（名词 la politique）、
  `manger`（名词 le manger）、`porter`（名词 le porter）都按名词义收录。

如果你想要的是「常见义项」，在生词本里直接改释义就行；但按等级划分的话，这类词的**新知识确实是它的名词用法**。

**② 它与 A1/A2 有 45 个词形重叠，这是正常的。**

重叠的是 `être`、`aller`、`avec`、`pouvoir`、`manger`、`porter`、`madame`、`cent` 这类词——
同一个词形，在 A1 学的是常用义，在 B1 学的是另一个义项。**它不是重复内容。**
导入时会看到「这个词已在别的词库里出现过」的提示，这是准确的信息，不是报错。

（另外与 `B2.csv` 重叠 28 条、与 `tech.csv` 重叠 20 条，同理。）

### 关于「为什么不是 3000 条」

常见说法里 B1 词汇量 2000–3000 指的是**累计量**（A1+A2+B1），不是单级新增量。口径也要对齐——
数字和本表都是 **lemmes（词族）** 口径：`parler / parle / parlais / parlé` 算 1 个。

FLELex 给出的是「最典型属于哪一级」，累计起来是：A1 1247 → A1+A2 约 1900 → 到 B1 约 3700 → 到 B2 约 8800。
如果你想再要一份**完整 A2** 或**完整 B2**，用同一套产线跑一遍即可（见 `B1.csv` 的生成方式）。

## 关于分级依据（说清楚，别当官方词表用）

**CEFR 官方不发布词汇表**，任何声称「官方 A1 词表」的都是二次整理。手工那五份是这样来的：

- 以「A1 能完成自我介绍与基本需求、A2 能应付日常情境、B1 能就熟悉话题独立表达、B2 能就广泛话题展开论证」这条能力线为骨架；
- 按主题分块收词（问候 / 数字 / 时间 / 家庭 / 食物 / 交通 / 城市 / 健康 / 学校 / 工作 / 天气……），
  保证每个等级内部自成体系、能立刻用起来，而不是按字母表摊平；
- **B2 的选词偏向「能拿来说理和读评论」**：观点论证（`enjeu` `fondement` `corollaire`）、社会制度（`institution` `réforme` `inégalité`）、
  抽象机制（`phénomène` `mécanisme` `dispositif`）、情绪细腻层次（`résignation` `perplexité` `bienveillance`）、
  以及 19 条**语篇连接词**（`en définitive` `force est de constater` `dans la mesure où`…）。

`B1-表达.csv` 单独存在的理由：FLELex 是**词根表**，收不进 `je pense que`、`en effet`、`se rendre compte`、
`avoir tort` 这类固定搭配和语篇连接词。这 143 条是从手工精选里挑出来、FLELex 覆盖不到的部分，
与 `B1.csv` **零重复**，两份合起来才是完整的 B1。

边界词各家都在打架（`développement` 到底算 B1 还是 B2），遇到跟教材不一致的，直接在生词本里改所属词库就行。

## 想自己加词

直接往 CSV 里追加行就行，注意几点：

- 六个字段全部用英文双引号包起来（现在的文件就是这样），这样字段里出现英文逗号也不会串列；
- 加了含英文逗号或引号的字段时，引号要写成两个（`""`）转义；
- 存成 **UTF-8（带 BOM）**。用 Excel 另存为「CSV UTF-8（逗号分隔）」即可；如果存成 GBK，小程序会给出编码告警而不是硬解出乱码；
- 单次导入上限 2000 行 / 30 列，单元格 300 字符。

旧版 `.xls`（Excel 97-2003 二进制格式）端上读不了，请另存为 `.xlsx` 或 `.csv`。
